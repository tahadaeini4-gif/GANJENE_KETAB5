# گنجینه ی کتاب

اجرا:  `npm start`  (یا `node server.js`) — فقط Node.js 18+ لازم است. پورت: `PORT=80 node server.js`

- داده‌ها در `data/state.json` ذخیره می‌شود (از گیت ایگنور شده). با F5 چیزی پاک نمی‌شود و تغییرات هر کاربر ظرف ۴ ثانیه برای بقیه می‌آید.
- ظاهر سایت (بوت‌استرپ/آیکن/فونت) فایل‌هایی کنار همین فایل‌ها هستند (پوشه لازم نیست). اگر نبود، سرور هنگام اجرا (با اینترنت) خودکار دانلود می‌کند،
  یا دستی: `npm run libs`. برای استفاده روی نت ملی، یک بار با اینترنت اجرا کنید و فایل‌های دانلودشده (css/js/woff2) را هم commit کنید.
- توجه: GitHub Pages فقط سایت ایستا می‌دهد و این پروژه سرور دارد؛ برای اجرا باید روی هاستی که Node.js اجرا می‌کند (مثلاً هاست/VPS ایرانی) deploy شود.
